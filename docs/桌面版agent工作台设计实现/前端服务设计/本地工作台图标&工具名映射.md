# 本地工作台图标与工具名映射

## 1. 设计目标

本地工作台在展示 Agent Loop 中间过程时，应优先向用户表达“当前正在做什么”，而不是直接暴露底层工具的技术名称。

图标用于快速识别工具类型，文案则优先展示工具调用的意图。当缺少意图描述时，才回退展示原始工具名。

## 2. 工具行展示优先级

优雅模式下的工具行按以下规则渲染：

1. 解析工具入参中的 `__thought` 字段，并兼容 `_thought` 字段。
2. `__thought` 存在且为非空字符串时，只展示意图文案，不显示 `toolName`。
3. `__thought` 不存在、为空或入参无法解析时，回退展示 `toolName`。
4. 工具完成后显示耗时；执行中显示加载状态。
5. 点击工具行仍可展开查看返回结果，隐藏工具名不影响详情查看。

示例：

| 工具名 | `__thought` | 主界面展示 |
| --- | --- | --- |
| `bash` | `查看当前工作空间根目录内容` | 终端图标 + `查看当前工作空间根目录内容` + 耗时 |
| `bash` | 空 | 终端图标 + `bash` + 耗时 |
| `search` | `搜索项目中的配置文件` | 通用工具图标 + `搜索项目中的配置文件` + 耗时 |

## 3. 图标映射

### 3.1 命令终端类

工具名转为小写后，包含下列任一关键字时，使用“终端窗口 + `>_`” SVG 图标：

- `bash`
- `shell`
- `terminal`
- `exec_command`
- `command`

终端图标使用 `currentColor` 继承工作台主题色，完成态使用低饱和蓝灰色，与过程文字层级保持一致。

### 3.2 其他工具

未命中专用图标映射的工具，完成后默认使用通用扃手 SVG 图标。执行中的所有工具统一使用加载图标，避免静态图标误导用户认为操作已完成。

## 4. 实现位置

- 工具行组件：`agentforge-desktop-ui/src/modes/elegant/ElegantToolItem.vue`
- 意图参数名：优先使用 `__thought`，同时兼容 `_thought`
- 终端类识别计算属性：`isTerminalTool`
- 意图文案计算属性：`thought`

## 5. 扩展约定

1. 新增工具专用图标时，优先在组件内建立类型判定，不应在模板中散落多组字符串判断。
2. SVG 应使用 `currentColor`，便于主题、状态和深浅色模式统一调整。
3. 工具名仅是缺少意图文案时的降级信息，不应与 `__thought` 重复展示。
4. `__thought` 属于用户可见的过程摘要，内容应简洁、明确，不应包含密钥、完整命令入参或其他敏感信息。
