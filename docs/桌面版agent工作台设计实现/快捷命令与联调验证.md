# 快捷命令与联调验证

## 0. 环境体检（启动前先跑）

```bash
cd agentforge-desktop-ui
npm run doctor
```

`doctor` 是只读检查，统一核验 Node/npm/JDK 8/Maven/AgentForge 核心构件/前端依赖/runtime JRE+runtime JAR/磁盘空间/目录权限。`[fail]` 必须处理后才能继续，脚本退出码非 0 时表示存在硬性缺失。

脚本目录已按职责分层：`scripts/lib`（共享模块）、`scripts/dev`（Vite + Electron）、`scripts/build`（JAR/JRE/runtime 准备）、`scripts/package`（打包）、`scripts/verify`（产物校验）、`scripts/doctor.mjs`（环境体检）。

## 1. 快捷启动后端服务

### 方式 A：IDE 启动（推荐调试用）

在 IDE 中运行 `AgentForgeDesktopServerApplication`，或命令行：

```bash
cd agentforge-desktop-server
mvn spring-boot:run
```

默认监听 `127.0.0.1:43178`，无 Token（仅本机开发）。

指定端口与数据目录：

```bash
mvn spring-boot:run \
  -Dspring-boot.run.arguments="--server.port=43178 --agentforge.desktop.root-dir=$HOME/.agentforge-desktop"
```

### 方式 B：直接运行 JAR

```bash
cd agentforge-desktop-server
mvn clean package -DskipTests
java -jar target/agentforge-desktop-server.jar
```

### 方式 C：桌面端内置启动

```bash
cd agentforge-desktop-ui
npm run desktop:dev:embedded
```

该命令会自动执行：

```text
build:server -> runtime:server -> Vite + Electron(embedded)
```

## 2. 工作台调试启动（对接本地已启动后端）

先按第 1 节启动后端（43178），然后：

```bash
cd agentforge-desktop-ui
npm install
npm run desktop:dev
```

默认连接 `http://127.0.0.1:43178`。

连接其他端口：

```bash
AGENTFORGE_DESKTOP_SERVER_URL=http://127.0.0.1:43179 npm run desktop:dev
```

后端启用 Token 时：

```bash
AGENTFORGE_DESKTOP_SERVER_URL=http://127.0.0.1:43178 \
AGENTFORGE_DESKTOP_SERVER_TOKEN=your-token \
npm run desktop:dev
```

只调试浏览器（不启动 Electron）：

```bash
npm run dev
```

浏览器通过 Vite 代理访问后端：

```bash
VITE_PROXY_TARGET=http://127.0.0.1:43178 npm run dev
```

## 3. 快捷一键打包（三端）

### 当前机器自动识别

```bash
cd agentforge-desktop-ui
npm run package:current
```

macOS arm64 -> `mac-arm64`，macOS Intel -> `mac-x64`，Windows x64 -> `win-x64`。

### macOS 双架构

```bash
npm run package:mac -- --arch arm64
npm run package:mac -- --arch intel
```

等价于：

```bash
npm run package:mac-arm64
npm run package:mac-x64
```

### Windows x64

在 Windows x64 构建机上：

```bash
npm run package:win-x64
```

### 三端命令总览

| 目标 | 命令 | 产物 |
| --- | --- | --- |
| macOS arm64 | `npm run package:mac-arm64` | `AgentForge Desktop-<version>-mac-apple-silicon-arm64.dmg/.zip` |
| macOS x64 | `npm run package:mac-x64` | `AgentForge Desktop-<version>-mac-intel-x64.dmg/.zip` |
| Windows x64 | `npm run package:win-x64` | `AgentForge Desktop-<version>-win-x64.exe` |

打包前准备：

- 后端 JAR：脚本自动执行 `build:server`。
- JRE 8：脚本自动从 `JAVA_HOME` / Zulu 8 / `packaging.config.local.json` 查找。
- 三端都必须准备对应架构的 JRE 8。

`packaging.config.local.json` 示例：

```json
{
  "jreHomes": {
    "mac-arm64": "/Library/Java/JavaVirtualMachines/zulu-8.jdk/Contents/Home",
    "mac-x64": "/path/to/macos-x64-jre-8/Contents/Home",
    "win-x64": "C:\\Tools\\jre8-win-x64"
  },
  "jreArchives": {
    "win-x64": "/path/to/jre8-win-x64.zip"
  }
}
```

产物目录：`agentforge-desktop-ui/release/`

## 4. 打包链路说明

```text
npm run package:*
  -> scripts/build/build-server.mjs          构建 agentforge-desktop-server.jar
  -> scripts/build/prepare-server.mjs        复制到 runtime/server
  -> scripts/build/prepare-jre.mjs           准备对应架构 JRE 8 -> runtime/jre
  -> vite build                              构建前端 dist
  -> electron-builder                        生成安装包
  -> scripts/verify/verify-*.mjs             校验 runtime/jre 与 runtime/server 是否打入
```

electron-builder 使用本地 `node_modules/electron/dist`，不会重复联网下载 Electron。

## 5. 常用环境变量

```text
AGENTFORGE_DESKTOP_SERVER_URL      连接外部后端
AGENTFORGE_DESKTOP_SERVER_TOKEN    外部后端 Token
AGENTFORGE_DESKTOP_ROOT_DIR        数据根目录
AGENTFORGE_DESKTOP_PORT            固定端口
AGENTFORGE_DESKTOP_CONFIG          主配置文件路径
AGENTFORGE_DESKTOP_JAVA_HOME       构建/开发用 JDK 8
AGENTFORGE_DESKTOP_JRE_HOME_*      打包用 JRE 8
AGENTFORGE_HOME                    AgentForge 源码目录
AGENTFORGE_DESKTOP_MODEL_API_KEY   默认模型密钥
VITE_PROXY_TARGET                  浏览器开发代理目标
```
